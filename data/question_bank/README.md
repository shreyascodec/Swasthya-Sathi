# Intake question bank

Clinician-reviewed intake question **patterns** (~15-20, derived from MediTOD
slots) live here as YAML in Phase 6: *gap*, *missing-report*,
*condition-follow-up*, *standard-history*.

The model may only phrase/translate a pattern from this bank — it may never
invent a question (product invariant). Placeholder only in Phase 0.
